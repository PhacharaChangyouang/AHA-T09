# Test evidence

หลักฐานต้นฉบับอยู่ในชุดเอกสารทีมเดิม ยังไม่ได้นำภาพและรายงานภายในเข้ามา เพราะต้องตรวจข้อมูลส่วนบุคคล ข้อมูลระบบจริง และรายละเอียดการปฏิบัติงานก่อน

หลักฐานที่จะเผยแพร่ต้องระบุเวอร์ชันที่ทดสอบ ขอบเขต วิธีทดสอบ ผลจริง และข้อจำกัด แยกผลของระบบต้นฉบับจากผลของ Academic Edition ห้ามอ้างว่าผ่านการทดสอบใน AHA-T09 จนกว่าจะรันและยืนยันจริง
